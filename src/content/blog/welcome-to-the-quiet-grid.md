This is a draft placeholder demonstrating the blog format. It is excluded
from the built site while `draft: true` is set in the frontmatter above.

To publish an article: write it as a Markdown file in `src/content/blog/`,
set `draft: false`, review it locally, then push to GitHub — Netlify builds
and publishes it automatically.

Frontmatter fields: `title`, `description`, `publishDate` (YYYY-MM-DD),
`book` (`bible-verse-sudoku`, `usa250-sudoku`, or `none` — adds a quiet
link card to that book at the end of the article), optional `module`
(campaign module id, e.g. `M1`), and `draft`.
